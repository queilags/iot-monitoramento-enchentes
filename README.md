# Sistema Inteligente de Monitoramento Ambiental com IoT para Prevenção de Enchentes e Deslizamentos Urbanos

## Descrição

Este projeto apresenta um sistema de monitoramento ambiental baseado em Internet das Coisas (IoT), desenvolvido para auxiliar na prevenção de enchentes e deslizamentos urbanos.

A solução utiliza sensores de nível de água, umidade do solo e chuva conectados a uma plataforma NodeMCU ESP8266. Os dados coletados são transmitidos utilizando o protocolo MQTT para monitoramento remoto em tempo real.

## Objetivos

* Monitorar condições ambientais críticas;
* Detectar riscos de enchentes;
* Detectar saturação do solo associada a deslizamentos;
* Emitir alertas locais através de buzzer, LEDs e módulo relé;
* Transmitir informações em tempo real utilizando MQTT.

## Componentes Utilizados

* NodeMCU ESP8266
* Sensor de Nível de Água
* Sensor de Umidade do Solo
* Sensor de Chuva
* Buzzer
* LEDs Indicadores
* Módulo Relé
* Protoboard
* Jumpers

## Ferramentas Utilizadas

* Arduino IDE
* MQTT Explorer
* Broker MQTT HiveMQ
* Fritzing

## Tópicos MQTT

* monitoramento/nivel_agua
* monitoramento/umidade_solo
* monitoramento/chuva
